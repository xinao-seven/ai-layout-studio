# Evaluation reports

Reports in this folder (`eval/reports/YYYY-MM-DD*.json`) are the only source for
README metrics. `m4-eval.json` is generated by `pnpm eval`; the M1–M3, live-model
and performance files are recorded manually from the commands cited in each
file (PRD §6.8, §13).
